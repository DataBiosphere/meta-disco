### Steps read from file content

Inference reads a VCF's producer command lines, chains them by matching outputs to inputs, and takes the one end of that flow as the step that made the file (#609). *stepped*: a `HaplotypeCaller` gave a `VariantCallActivity`, or a bcftools `concat` a `MergeActivity` (#610), whose parents all resolved; *no_command_line* / *unknown_tool*: nothing to read, or a tool whose arguments are not declared; *no_single_end* / *output_not_this_file*: the flow has no one end that made this file; *no_activity*: the producing step is not one a rule takes: no rule for its tool in that family, a `HaplotypeCaller` without exactly one alignment input, or a `concat` that does not join two or more VCFs or reads one from stdin; *parent_not_found* / *parent_ambiguous*: an input's name no file of the dataset carries, or more than one does (or two inputs share it); for a `HaplotypeCaller`, several alignments carrying the name are *stepped* where exactly one's `@SQ` names and lengths are all among the VCF's `##contig`s (#620); *parent_unreadable*: one of those alignments' headers could not be read, or names no contig or one without a length, so none is taken; *not_a_vcf*: a PLINK 2 `.pvar`, whose header is the VCF's it was converted from, so its command lines never name the step that made the `.pvar` (#561). The tar and sample-map producers read T2T's joint-calling cohort (#621): a GenomicsDB workspace tar's `vcfheader.vcf` gives a `CohortMergeActivity` from its sample map, and a sample map's rows a `CohortDefinitionActivity` of its gVCFs; a tar that is no GenomicsDB workspace is not counted; *no_vcf_header*: the workspace has no `vcfheader.vcf` where it was looked for; *vcf_header_unreadable*: reading it failed, and the next run reads it again; *output_not_this_file*, for a tar: the import's workspace names another directory; *not_a_list*: the file is not two tab-separated columns naming VCFs, or three with an index path. A tar counted *parent_not_found* here may still get its step at reconcile, through a sample map held outside AnVIL (#710, below). A tar in a folder whose maps are rebuilt (ANVIL_T2T_CHRY's SGDP tars, #726, below) is *stepped* through the list rebuilt from its own samples; *map_not_in_layout*: its map is none the run's layout places gVCFs for; *no_samples*: its `callset.json` gave no samples; *member_not_found* / *member_ambiguous*: a sample's gVCF no file, or more than one, carries in the tar's reference folder, or a sample listed twice. ## Samples: whose data each file holds

A file's own content names its samples, read by inference and labelled *header* below (a BAM's `@RG SM`, a VCF's sample columns, a GATK sample map's rows, #668), and a submitter table may name them in a column the slot map reads; each string becomes an identifier only through `rules/sample_namespaces.yaml` (#357). *named*: every string the header holds is recognised; *unrecognised*: it holds one no rule recognises (or a read group with no `SM`), so it names no samples; *no_sample*: it names none; *unread*: the head read ended before the samples (a VCF's `#CHROM` line). The repository's record of the step that generated a file names them too: AnVIL's `anvil_activity` (or `anvil_sequencingactivity`) rows generating the file, whose `used_biosample_id` ties to one of our sample records through the AnVIL ids listed on it (#698), labelled *activity*. A PLINK 2 fileset's `.pgen`, `.pvar` and `.log` take the samples of the `.psam` written beside them under the same stem, labelled *fileset* (#751). Settled: *agreed*, two or more of header, table, activity and fileset named the same samples; *header_only* / *table_only* / *activity_only* / *fileset_only*: only the header, only tables (one or several, agreeing), only the activity, or only the fileset's sample table did; *inherited*: only the file's parent did, across a step that passes samples (an index, checksum, QC report, coverage track or cohort merge, #668), and a parent agreeing with the file's own sources is listed beside them without changing its column; *conflict*: they named different samples in one namespace; *incomparable*: different samples in no shared namespace, which only a crosswalk could join (#361); *none*: no source named any. A conflict or an incomparable file gets no `samples`. A file whose name names one other sample than its settled ones is counted under *name disagrees*; a name is a check, never a source.
